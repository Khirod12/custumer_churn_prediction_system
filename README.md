# Deep Learning Customer Churn + Agentic AI

## What this version does

The primary churn predictor is a **Deep Neural Network (DNN)** implemented with PyTorch. The existing CatBoost model is preserved as a baseline artifact.

Flow:

Customer Data -> Preprocessing -> DNN -> Churn Probability -> Risk Tier -> Agentic AI -> Retention Offer

## Dataset

`data/Churn_Modelling.csv` is included for reproducible training. It is the Bank Churn_Modelling educational dataset. The dataset contains 10,000 customer records and the `Exited` target.

## DNN architecture

- Input: 16 engineered features
- Dense 64 + ReLU + BatchNorm + Dropout(0.25)
- Dense 32 + ReLU + BatchNorm + Dropout(0.20)
- Dense 16 + ReLU
- Dense 1 + sigmoid probability

SMOTE is applied only to the training partition, then StandardScaler is fit on the training data. The untouched test set is used for evaluation.

## Actual test metrics

- Accuracy: 80.00%
- Precision: 50.61%
- Recall: 71.50%
- F1-score: 0.593
- ROC-AUC: 0.855

These values were generated by actually training the DNN on the included dataset; they are not hard-coded demo numbers.

## Run locally

1. Create/activate a Python environment.
2. Install dependencies:

   `pip install -r requirements.txt`

3. The trained model and scaler are already included under `models/`.
4. Firebase is required for login and prediction persistence. Copy your own Firebase service-account JSON into the project folder and either keep the default filename expected by the app or set `FIREBASE_CREDENTIALS` to its path.
5. Start the application:

   `python app.py`

6. Open `http://127.0.0.1:5000`

## Retrain

If you change the dataset, run:

`python training/train_dnn.py`

This regenerates the DNN model, scaler, and metrics.

## Security

The original Firebase service-account credential was intentionally not redistributed in this final ZIP. Use your own credential file locally and never publish it to GitHub.
