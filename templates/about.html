Model Architecture

An in-depth look at the preprocessing, Deep Neural Network, and Agentic AI retention pipeline.

🛠️ Feature Engineering

To improve model robustness, the following interaction features were created from the raw dataset:

  • Age_Balance: Age × Account Balance
  • Tenure_Products: Tenure × Number of Products
  • Active_Balance: IsActiveMember × Balance
  • Credit_Age: CreditScore × Age
  • Products_per_Tenure: NumOfProducts / (Tenure + 1)
# Risk Score Logic
Age * 0.3 + Balance * 0.00001
+ (1 - IsActiveMember) * 2

⚖️ Preprocessing & Class Balance

The DNN uses a reproducible preprocessing pipeline. Categorical variables are encoded, numerical features are standardized, and SMOTE is applied only to the training partition so the test set remains untouched.

This gives the neural network balanced training examples while keeping evaluation representative of unseen customers.

🧠 Agentic Retention Layer

After prediction, a Retention Agent orchestrates perceive → predict → plan → act: it scores churn risk, maps probability to tiers (low / moderate / high / critical), and issues personalized coupons and offers based on account signals (activity, products, balance, tenure).

  • OfferAgent: Tier-based coupons (LOYAL10 → VIP40)
  • Personalization: Reactivation, card signup, bundle, wealth desk perks
  • Firebase: Stores agent plan, coupons, and offers with each prediction

🧠 Deep Neural Network

The primary churn predictor is a Deep Neural Network (DNN) implemented with PyTorch. It learns non-linear relationships among customer attributes and engineered features.

Input: 16 engineered features
Dense 64 → ReLU → BatchNorm → Dropout
Dense 32 → ReLU → BatchNorm → Dropout
Dense 16 → ReLU → Sigmoid output

📊 Final Model Performance

After tuning the classification threshold to 0.50, the model achieved the following results on the test set:

Accuracy 0.8502 (80.00%)
Precision (Class 1: Churn) 0.9446
Recall (Class 1: Churn) 0.8567
F1 Score 0.9039
ROC AUC Score 0.9092
